# Подборка базовых библиотек на C/CPP

> [English version](README.md)

> [China version](README_CN.md)

Самодостаточный набор небольших базовых библиотек на C/CPP:
парсер JSON, модуль логирования, модуль настроек и библиотека ecma
(UTF-8 кодек, регулярные выражения, буфер строк). Внешних зависимостей нет -
используется только стандартная библиотека C/CPP.

## Особенности проекта

- Самодостаточность: не требуются сторонние библиотеки, только стандартная библиотека C.
- Чистый C с обёртками `extern "C"` - код можно напрямую включать в CPP-проекты.
- Кроссплатформенность: Windows и POSIX (Linux/macOS).
- JSON: объекты, массивы, строки, числа, булевы значения, null; поддержка
  экранированных последовательностей, включая `\uXXXX` с кодированием в UTF-8.
- ecma: UTF-8 кодек (декодирование/кодирование, работа с кодовыми точками),
  движок регулярных выражений в стиле ECMAScript (группы, lookahead/lookbehind,
  глобальная замена с шаблоном или обратным вызовом) и динамический буфер строк.
  Используется парсером json и нормализатором orfo (русский текст для TTS).
- Логирование: уровни DEBUG/INFO/WARN/ERROR, вывод в консоль, файл, в оба
  одновременно или отключён; метки времени; обратный вызов для каждой
  сформированной строки (например, для рассылки по WebSocket).
- Настройки: чтение JSON-конфигурации, типизированные геттеры со значениями по
  умолчанию; ограничение размера файла конфигурации - 1 МБ.
- Потокобезопасное получение локального времени (`localtime_s` / `localtime_r`).

## Модули

- **json** - лёгкий парсер JSON: разбирает текст в дерево значений и
  предоставляет типизированный доступ к элементам.
- **log** - модуль логирования с уровнями важности, выводом в консоль/файл и
  обратным вызовом для каждой строки журнала.
- **sett** - модуль настроек: загружает JSON-конфигурацию и возвращает значения
  (int, bool, string) с запасными значениями по умолчанию.
- **ecma** - общая вспомогательная библиотека: UTF-8 кодек, движок регулярных
  выражений в стиле ECMAScript и динамический буфер строк. Зависимость модуля
  json и основа нормализатора orfo.

## Использование

### Сборка

Скомпилируйте нужные исходники вместе с вашим `main.c`:

- MSVC (Windows):

  ```
  cl /W4 json.c log.c sett.c ecma.c main.c
  ```

- GCC / Clang (Windows, Linux, macOS):

  ```
  gcc -Wall -Wextra json.c log.c sett.c ecma.c main.c -o app
  ```

### Файл конфигурации

Пример `config.json`:

```json
{
    "port": 443,
    "ssl_use": true,
    "root": "www"
}
```

### Пример кода

```c
#include <stdlib.h>
#include "log.h"
#include "sett.h"

int main(void) {
    log_init(LOG_OUTPUT_BOTH, LOG_LEVEL_INFO, "server.log");

    Sett *s = sett_init("config.json");
    if (!s) {
        LOG_ERROR("не удалось загрузить config.json\n");
        return 1;
    }

    int port = sett_get_int(s, "port", 443);
    bool ssl = sett_get_bool(s, "ssl_use", true);
    char *root = sett_get_string(s, "root", "www");

    LOG_INFO("port=%d ssl=%d root=%s\n", port, ssl, root);

    free(root);   // строки из sett_get_string выделяются в куче
    sett_free(s);
    log_close();
    return 0;
}
```

### Порядок работы

1. `log_init()` - инициализация логирования: куда выводить, минимальный уровень, имя файла.
2. `sett_init()` - загрузка и разбор файла конфигурации.
3. Чтение значений через `sett_get_int()`, `sett_get_bool()`, `sett_get_string()`.
4. `free()` для строк, полученных из `sett_get_string()`.
5. `sett_free()` - освобождение настроек.
6. `log_close()` - закрытие журнала.
